# API Documentation

## Base URL
`/api`

## Authentication Endpoints
- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/refresh`
- `POST /api/auth/logout`
- `GET /api/auth/profile`

## Item Endpoints
- `GET /api/items`
- `GET /api/items/:id`
- `POST /api/items`
- `PUT /api/items/:id`
- `DELETE /api/items/:id`
- `POST /api/items/sync/external`

## Query Parameters
- `search`
- `category`
- `status`
- `sortBy`
- `sortOrder`
- `page`
- `limit`
